Login System Application
Overview

This project is a simple Java Login and Registration System that validates user input and allows a user to register and log in. The system follows Object-Oriented Programming (OOP) principles and includes unit testing using JUnit 5.
Features
User Registration

The system allows a user to register by entering:

Username
Password
South African cell phone number
Validation Rules
Username
Must contain an underscore _
Must not be longer than 5 characters
